# Amazon Clone – Full Stack E-Commerce Application

A full-stack e-commerce web application inspired by Amazon’s UI/UX, built using Django.  
The project focuses on clean UI design, backend integration, and scalable architecture.

## Features
- User authentication and authorization
- Product listing with filters and advanced search
- Order management and user workflow
- Responsive UI inspired by Amazon’s design
- Backend integration for products, users, and orders

##  Tech Stack
- Backend: Django
- Frontend: HTML, CSS, JavaScript, Bootstrap
- Database: SQLite (default Django DB)
- Deployment: Render

## Project Status
Currently focused on frontend and core backend features.  
Future improvements include:
- Recommendation system
- Enhanced search and filtering logic
- Payment gateway integration

## Architecture
The application follows Django’s MVT architecture to maintain separation of concerns and scalability.
